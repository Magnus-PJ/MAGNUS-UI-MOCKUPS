Purpose & workflow: Regional rule packs bundle the compliance configuration for a region — PC-PNDT, GST profile, DPDP consent settings, retention classes. New pack versions ship with a human-readable diff, roll out through rings (sandbox → pilot tenant → all tenants), require tenant acknowledgement when a change is compliance-affecting, and can be rolled back at any ring boundary with four-eyes approval.
