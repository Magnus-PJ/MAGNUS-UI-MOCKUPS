MVP1-CORE
G4 Scheduling & Resource Setup — workspace 'Setup'
Baseline: EXTENDS · FO-S8 doctor availability
Purpose & workflow: Per-practitioner weekly duty grids control which blocks a doctor is bookable for performing (e.g. USG) and which are reserved for reading. Time-off requests run a coverage check against already-booked slots; conflicts become explicit reassign/reschedule tasks before approval can complete. For radiologists the reading-vs-performing split matters: reading blocks keep report SLAs alive without consuming bookable calendar slots.
