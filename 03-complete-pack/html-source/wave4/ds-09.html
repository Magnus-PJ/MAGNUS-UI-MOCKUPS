DS-09 Print & Document Templates Pattern

DESIGN SYSTEM
G17 Design System & Patterns — documentation pages
Baseline: NET-NEW · print/document template pattern
Purpose & workflow: Defines the letterhead zone model, immutability rules and physical output specs for every printed or PDF document Magnus produces — reports, invoices, receipts, consent copies, queue slips. Templates are tenant-brandable (white-label) but zone structure and statutory content are platform-enforced.

STATE B — RENDER RULES · WATERMARKS · SIGNATURE BLOCK
Versioned-immutable render rule core guarantee
A document renders forever exactly as first issuedEach issued document pins: letterhead version, statutory footer version, terminology/code-set version, template version and locale pack version. Later rebrands or template edits never alter an already-issued document — reprints re-render from the pinned versions.
EventEffect on issued documents
Tenant uploads new logo (letterhead v8 → v9)None. Report RPT-AW-2026-07-0921 issued under v8 reprints with v8 logo, plus DUPLICATE COPY watermark.
GSTIN or grievance officer changesNew documents use new footer version; old ones keep the footer that was legally in force at issue.
Report addendum signedNew document version v2 issued; v1 remains retrievable, watermarked SUPERSEDED — SEE ADDENDUM.
Template deleted by adminSoft-retire only; render engine keeps all historical versions. Hard delete does not exist.

STATE C — PHYSICAL OUTPUT SPECS (A4 + THERMAL SLIP)
A4 spec reports · invoices · consent copies
PropertySpec
PageA4 210 × 297 mm, portrait; landscape only for image-grid annexes
Margins18 mm left (filing), 12 mm others; printable-area safe zone enforced by renderer
TypographyBody 10.5 pt / 1.4; tables 9.5 pt; never below 8 pt (statutory footer 8 pt minimum)
ColourMust survive monochrome laser — colour is never the only signal (matches DS-08 rule)
PDF profilePDF/A-2b archival; fonts embedded incl. Devanagari subset (see DS-10)
Multi-pageZ1 compact variant (12 mm) + Z6 repeat on pages 2+; “page x of y” mandatory
Thermal slip spec queue tokens · payment receipts · 80 mm
PropertySpec
Width80 mm roll (72 mm printable); 58 mm degraded variant auto-selected by printer profile
HeaderText-only org name + branch (no logo raster unless printer ≥ 203 dpi mono bitmap)
ContentToken slips: token no. Q-047 in 24 pt, modality, est. wait, kiosk QR. No patient name, no MRN on queue slips (DS-07 public context).
ReceiptsReceipt no., date-time IST, masked payment ref (UPI ••••7712), amount ₹ Indian grouping, GSTIN, “duplicate” flag on reprint
FooterGrievance phone + “Full tax invoice available at desk / mgns.in/i/…” — statutory footer condensed, never dropped
Printer profilesBranch admin maps each printer (front-desk thermal, report laser) in OR-06; templates declare which profile class they target and refuse mismatched devices instead of mangling output.

Every render, print and reprint — with template version, letterhead version, printer, copy counter and printing user — is recorded in the access log.
