DESIGN SYSTEM
G16 + G17 — OPERATOR CONSOLE / DESIGN SYSTEM DOCS
Baseline: NET-NEW · codifies the vendor deck's implicit design system — tokens
Purpose & workflow: Single source of truth for the MagnusPRO visual language: colour tokens with strict semantic usage rules, the typography scale, the spacing grid and verified WCAG AA contrast pairings. Every screen in the MVP-1 pack must consume these tokens; hard-coded hex values outside this table are a review blocker. White-label tenants may re-skin only the tokens marked "themeable".
Theme coverageLIGHT THEME — SHIPPED (MVP-1)DARK THEME — ROADMAP (post-MVP, token-mapped, no screen rework expected) All tokens below are defined for light theme; dark values will map 1:1 onto the same token names.
