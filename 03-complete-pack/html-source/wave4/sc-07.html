Walk-in ratio = share of each hour's capacity servable without a booking. Every overbook above the booked grid demands a named approval by the configured role, captured in the usage report below. STAT reserve slots are invisible to the public booking flow and release to walk-in 30 min before slot start if unused.
Guardrails
✓Overbook max/day is a hard ceiling — the approval role cannot exceed it; only this Setup screen can raise it (with change audit).
✓MRI walk-in ratio locked at 0% — MRI safety screening requires a pre-visit questionnaire; unlockable only by org admin with step-up.
✓Alert branch head when overbook usage exceeds 80% of ceiling for 3 consecutive days.
 Allow cross-modality walk-in overflow (US → X-ray) — off.
