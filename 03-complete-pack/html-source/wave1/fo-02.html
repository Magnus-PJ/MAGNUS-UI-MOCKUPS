Baseline: EXTENDS · FO-S2 Patient search
Purpose & workflow: Front-office staff search before every booking or registration so duplicates are never created. Exact identifiers (MRN, phone, ABHA, insurance ID) return authoritative hits; name + DOB runs a fuzzy match with confidence chips. The screen must guarantee that every search is recorded with a purpose, results are masked to the minimum needed to disambiguate, and a failed search never shows a partial list that could be mistaken for "no match".
