Resend rules (enforced)
Max resends
3 per event per channel (report-ready, invoice, receipt)
Cooldown
30 minutes between resends of the same event
Beyond limit
Escalate to front-office call task — never more messages
Suppression
Resend honours suppressions & quiet hours; no override
Retention
Message metadata and template version are retained 3 years for audit. Rendered secure-link tokens expire after 30 days and are never stored in this log. Access to this log is itself logged.
