Purpose & workflow: Org admin migrates legacy data (patients, visits, reports, referrers) from prior systems in controlled batches. Every batch runs a mandatory dry-run with an error report before execution; execution needs four-eyes approval. Imported patients carry consent state "legacy — notice at next visit" until DPDP notice is served. A batch can be reversed only while no new activity has touched its records.
