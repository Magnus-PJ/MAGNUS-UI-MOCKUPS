MVP1-CORE
G14 Governance & Compliance — workspace 'Governance'

Purpose & workflow: Unified queue for DPDP data-principal rights requests — copy of records, correction, and nominee designation — each on a statutory 30-day SLA. Copy requests compile a scoped, watermarked export delivered via a secure Patient Tracker link after Privacy Officer approval; corrections are guarded so clinical report changes route through the radiologist addendum workflow while demographics can be applied directly; nominee changes require identity verification. Every decision syncs status back to the patient's tracker link.
