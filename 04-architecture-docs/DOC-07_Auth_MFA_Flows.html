2 · Core flows (ordered screen chains)
FlowChain & behaviour
First activationInvite → AU-07 (accept, set password, MANDATORY MFA enrolment inline via AU-04 incl. backup codes, policy acceptance) → AU-10 workspace chooser.
Daily sign-inAU-01 (credentials) → AU-03 (2FA: passkey preferred / TOTP / backup code) → AU-10 (workspace + branch context) → workspace.
Failure branchesAU-02: wrong password (attempts left) → throttle 30s → LOCKOUT (self-recovery AU-06 or admin AU-14). Wrong OTP → retry w/ resync hint. Expired invite → AU-07 request-new. Suspended → distinct message, no enumeration.
Lost authenticatorAU-05: identity proofing (password + manager/admin approval task AU-14 + optional cooling period) → all sessions revoked → re-enrol AU-04.
Password resetAU-06: request (same response always) → email link + OTP → new password (policy: 12+ chars, history 5) → all sessions revoked.
Shared counterAU-08: auto-lock on walk-away → badge/PIN fast user switch (<3s) → whose-session banner always visible. Personal lock: PIN/password resume.
Step-up (high-risk action)AU-09: action triggers modal → mechanism named (password/TOTP/passkey per org policy) → short-lived token bound to session + TARGET OBJECT (anti-CSRF/replay) → action executes → audit.
IdP unreachableAU-13: cached recent sessions continue read-limited; new sign-ins blocked w/ retry; branch-admin emergency local access w/ paper log; auto-recovery banner.
Patient linkPT-01: link → OTP to ••••4821 → 3 attempts → 30-min pause → view (15-min window). Expired → PT-03 request-new (registered mobile only). Changed number → in-person with ID only (hijack guard, FO-07 OTP-verified change).

4 · Session lifecycle & admin operations
Timeouts
Per workspace (AU-15): shared counters short (5 min lock), reading workstations longer; absolute session max 12 h.
Concurrency
Concurrent distant sign-ins flagged (AU-17); same study open by two readers warned (RD-04).
Revocation
Self-service per device (AU-11); org-wide force sign-out w/ reason (AU-17); automatic on password reset / factor loss.
Service accounts
AU-18: least-privilege scopes, key rotation with dual-key overlap, last-used tracking, secrets shown once.
Policy gates
AU-12: updated AUP/privacy notice blocks after N deferrals; per-version acceptance recorded.
